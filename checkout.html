14-lesson course

Systems-oriented curriculum.

  1. Toolchain baseline — compiler modes, warnings, debug vs. release.
  2. Object lifetime & storage — pointers, references, lifetime, ownership boundaries.
  3. Ownership & RAII — smart pointers and deterministic cleanup.
  4. Interfaces & APIs — headers, abstractions, ABI awareness.
  5. Containers & algorithms — iterators, invalidation, complexity.
  6. Error handling — exceptions, status values, invariants.
  7. Native debugging — GDB-oriented breakpoints, backtraces, watchpoints, crash analysis.
  8. Sanitizers & UB — ASan/UBSan and toolchain-supported leak checks.
  9. CMake & build systems — targets, dependencies, compiler selection.
  10. Performance reasoning — measurement, profiling strategy, allocation/cache behavior.
  11. Concurrency — threads, synchronization, races, shared state.
  12. Systems interfaces — files, processes, sockets, OS boundaries.
  13. Architecture & refactoring — decomposition, testability, modernization.
  14. Capstone review — apply the workflow to a real program or project.
